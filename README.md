# Efficient_2-D_FIR_Filter_using_Reconfigurable_Multiplier
Designed a 2-D FIR filter using Verilog HDL for image denoising and real-time processing. Optimized hardware using a reconfigurable multiplier, coefficient symmetry, and efficient adders to reduce area, power, and delay. Simulated with Vivado, synthesized using Cadence at 45 nm, and evaluated image quality using MATLAB (PSNR and SSIM).
